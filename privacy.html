Privacy Policy — Automate Blogspot Download

Last updated: October 11, 2026

What this app is

Automate Blogspot Download is a personal backup tool used only by its owner to archive the owner's own Blogger blogs. It is not a public service and has no other users.

Data accessed

With the account owner's permission, the app uses the Google Blogger API with the read-only scope (https://www.googleapis.com/auth/blogger.readonly) to read the owner's blogs, posts, pages, and comments.

How data is used and stored

  • Data is used only to create a backup copy for the account owner.
  • Backups are stored in storage controlled solely by the owner.
  • No data is sold, shared with, or transferred to any third party.
  • No data is used for advertising, analytics, or training any model.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
